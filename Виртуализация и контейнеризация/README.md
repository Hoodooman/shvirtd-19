# 🐳 Основные команды Docker

| Категория               | Команда                                                | Описание                                                          |
|-------------------------|--------------------------------------------------------|-------------------------------------------------------------------|
| Управление контейнерами | docker run -d -p [хост:контейнер] --name [имя] [образ] | Создать и запустить контейнер в фоне .                            |
|                         | docker start/stop/restart [контейнер]                  | Запустить, остановить, перезапустить контейнер .                  |
|                         | docker exec -it [контейнер] [команда]                  | Выполнить команду в запущенном контейнере (например, /bin/bash) . |
|                         | docker rm [контейнер]                                  | Удалить остановленный контейнер .                                 |
|                         | docker rename [старое_имя] [новое_имя]                 | Переименовать контейнер .                                         |
| Мониторинг и логи       | docker ps или docker container ls                      | Показать запущенные контейнеры .                                  |
|                         | docker ps -a                                           | Показать все контейнеры (включая остановленные) .                 |
|                         | docker logs [контейнер]                                | Показать логи контейнера .                                        |
|                         | docker inspect [контейнер]                             | Показать детальную информацию о контейнере .                      |
|                         | docker stats [контейнер]                               | Показать статистику использования ресурсов .                      |
| Управление образами     | docker build -t [имя:тег] .                            | Собрать образ из Dockerfile в текущей директории .                |
|                         | docker pull [образ]                                    | Скачать образ из реестра .                                        |
|                         | docker images                                          | Список локальных образов .                                        |
|                         | docker rmi [образ]                                     | Удалить локальный образ .                                         |
| Очистка                 | docker system prune                                    | Удалить все неиспользуемые данные (контейнеры, образы, сети) .    |
|                         | docker volume prune                                    | Удалить все неиспользуемые тома .                                 |

# 🎵 Основные команды Docker Compose

Docker Compose используется для управления многоконтейнерными приложениями через файл docker-compose.yml

| Команда                                | Описание                                              |
|----------------------------------------|-------------------------------------------------------|
| docker compose up -d                   | Создать и запустить все сервисы в фоновом режиме .    |
| docker compose down                    | Остановить и удалить все контейнеры, сети .           |
| docker compose start/stop/restart      | Запустить, остановить или перезапустить все сервисы . |
| docker compose ps                      | Показать статус контейнеров проекта .                 |
| docker compose logs [сервис]           | Показать логи конкретного сервиса .                   |
| docker compose exec [сервис] [команда] | Выполнить команду в контейнере конкретного сервиса .  |
| docker compose build                   | Пересобрать образы сервисов .                         |
| docker compose pull                    | Скачать самые свежие образы для сервисов .            |

# 💡 Полезные советы

Флаги для docker run: Флаги -it часто используются вместе для запуска интерактивного контейнера с псевдо-TTY . Флаг --rm автоматически удалит контейнер после его остановки .

Флаги для docker compose: Флаг -f позволяет указать конкретный Compose-файл, а -p — задать имя проекта .

Постоянные данные: Используйте docker volume create и монтируйте том в контейнер с помощью -v в docker run или через секцию volumes в docker-compose.yml, чтобы данные сохранялись после удаления контейнера .
